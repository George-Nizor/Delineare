# Freehand boxes

Once you can plot a box with a ruler, you can learn to draw one freehand at any angle. In this lesson you'll draw boxes without a ruler, draw through them, and check each one by extending its edges back to see whether they meet.

## Steps

1. **Mark the vanishing points.** Put three vanishing points on the page, close enough to fit on it. Give each box its own symbol for its points (an O, an @, a #) so you can tell them apart.

2. **Draw a Y.** Draw three lines that meet at one point, with angles between them greater than 90 degrees. The meeting point is the box's nearest corner. Drawabox names this the **Y method**.

3. **Draw the box.** Ghost and draw the remaining edges, each one aimed at its vanishing point. Draw all twelve, including the hidden ones, as if the box were see-through.

4. **Extend the edges.** In ballpoint, start at the centre of the Y and extend each edge back, away from you. Do this on every box when the page is done. See how far each line is from its vanishing point.

5. **Fill the page.** Draw five or six boxes per page, varying the Y each time. Use what the extensions showed on the next page.

Drawabox sets this as the first fifty boxes of its 250 Box Challenge.

## Common mistake

The most common mistake is fixing the back corner. It looks wrong, so you want to correct it. But it's only a symptom of edges that don't converge consistently. Look at each set of edges, not the corner.

## Checking your page

Check these on each page:

1. Every box has all twelve edges.
2. No set of edges is parallel on the page.
3. Extensions start at the nearest corner and run away from you.
4. Each set of extended edges heads toward its vanishing point.

The extensions will rarely hit the points. They show you which way you drifted.
